# Visual asset provenance

- `player-red.png`, `player-overworld.png`, `item-ball.png`, `badges.png`, and `trainers/*.png` are the PNG
  sources from [`pret/pokered`](https://github.com/pret/pokered) commit
  `0cd19d3b877b7dc66d12c7050bed9a7f38154d4b`. They reproduce graphics from
  Pokémon Red and Blue and are used here for identification in a local fan
  companion.
- `kanto-town-map-rby.png` is the 160 × 136 Generation I Town Map image from
  [Bulbagarden Archives](https://archives.bulbagarden.net/wiki/File:Kanto_Town_Map_RBY.png),
  where it is identified as a game screenshot used under fair use.
